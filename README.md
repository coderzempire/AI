# 🌸 Aria - Personal AI Assistant

> Ek sweet, caring female AI assistant jo Hindi + English dono bolti hai 💖

## ✨ Features

- 🎀 **Customizable Name** - Apne hisaab se naam rakho
- 🗣️ **Hindi + English** - Dono languages support
- 🎵 **Sweet Female Voice** - 6 Indian voices me se choose karo
- 🎨 **Animated Avatar** - 6 cute Indian girl characters
- 🧠 **Memory** - Tumhari baatein yaad rakhti hai
- 💕 **Caring Persona** - Pyar se baat karti hai
- 🎤 **Voice Cloning** *(coming soon)* - Apni voice se clone

## 🚀 Tech Stack

- **Backend:** Python + FastAPI
- **Brain:** Groq (Llama 3.1)
- **Voice:** Edge-TTS
- **Memory:** SQLite
- **Deploy:** GitHub Codespaces

## 📦 Setup

```bash
pip install -r requirements.txt
python app/main.py
